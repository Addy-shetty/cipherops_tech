Labs in your own AWS account

Every template is small, cheap and has a cleanup step. Use a separate sandbox account, never production.

Set up safely (once)

  1. Create a sandbox account, ideally in an AWS Organization so you can close it later.
  2. In AWS Budgets, create a zero spend budget or a small monthly budget with email alerts.
  3. Sign in with IAM Identity Center or an MFA-protected admin, never the root user.
  4. Open AWS CloudShell in one Region (for example us-east-1). The AWS CLI is already installed there.
  5. Upload the template (CloudShell → Actions → Upload file), then run the deploy command from the lab.
  6. When you finish, run the cleanup steps and check aws cloudformation list-stacks --stack-status-filter CREATE_COMPLETE shows nothing from cipherops.
